How It Works

Simple self-service, in three steps.

Every user follows the same easy flow, with nothing to install or learn.

1

Enter With Credentials

Couriers and recipients get door access with a card, code or app.

2

Log & Notify

Each parcel is scanned in and the recipient is told it has arrived.

3

Pick Up

The recipient enters, collects the parcel and the pickup is recorded.

FAQ

Smart Package Rooms, answered.

How is a package room different from lockers?

It is a controlled room with logging and notifications, suited to large or bulky volumes.

Can it work with lockers too?

Yes. Many sites combine a room for bulky items with lockers for small parcels.

How is access controlled?

By card, code or app, with a record of every entry.

Can recipients sign for items?

Yes. Pickup confirmations can be recorded in the software.
