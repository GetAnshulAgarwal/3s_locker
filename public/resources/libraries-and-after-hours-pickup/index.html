Libraries and After-Hours Pickup

Lockers let members collect holds and return items outside staffed hours, which makes the library useful for people with busy schedules.

← All resources

📚 1. Hold pickup

Staff place reserved items into lockers and the member is notified. The member collects at any time without waiting at the desk.

📚 2. After-hours returns

Return lockers accept items when the library is closed, and each return is logged so the record is up to date the next morning.

📚 3. Lending devices

Laptops, readers and tablets can be issued from lockers to authorised members and returned the same way.

📚 4. Benefits for staff

Fewer routine hand-offs leave staff free to help members with research, events and reading programmes.
